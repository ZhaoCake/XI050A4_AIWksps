# 卡莱特i9+ v6.1 pinout

### Component

- FPGA
   XC7A50T-FGG484
- SDRAM
   M12L64322A 8MB SDRAM (512K x 32 Bit x 4 Banks)
- SPI Flash
   MX25L128 16MB
- Ethernet PHY
   1Gb Ethernet PHY Broadcom B50612D x 2

| Pin  | Function |
| ---- | -------- |
| J5   | TCK      |
| J4   | TMS      |
| J3   | TDI      |
| J2   | TDO      |

### Clock



A 25Mhz clock is connected to FPGA with pin K4
